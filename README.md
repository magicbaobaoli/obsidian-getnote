# 得到大脑 Get笔记 · Obsidian 插件

把「得到大脑（Get笔记）」搬进 Obsidian。**本地优先**：笔记就是你自己库里的 Markdown 文件，
浏览、搜索、编辑、删除全部离线可用；云端同步、录音卡导入是需要时再打开的增强项。

> 这是 [dsh-getnote](https://github.com/magicbaobaoli/dsh-getnote)（DeepSeek Harness 版）的 Obsidian 移植。
> 功能对齐，但宿主不同：那边挂在 DSH 的 webServer 上，这边是一个标准 Obsidian 插件。

---

## 功能

### 本地笔记库

- **三栏面板**：目录树 / 笔记列表 / 正文，支持按目录、标签、关键词过滤，两种排序。
- **Markdown 原样渲染**：标题、列表、表格、引用、代码块、任务清单、内嵌图片与音频。
- **编辑与保存**：面板内直接改正文并保存；每次保存前自动在 `.history/` 留一份快照，可回滚。
- **新建 / 删除**：新建可指定目录与日期前缀；删除进 `.trash/`，可还原、可彻底清除。
- **搜索**：全文搜索，支持 `tag:` 与 `path:` 限定语法，结果带上下文片段。
- **反链与大纲**：`[[wikilink]]` 反链、标题大纲、冲突文件（`.conflicts/`）识别与解决。
- **标签**：重命名、删除、批量改写，标签面板带计数。
- **热力图**：按天统计的写作/导入活动。
- **三栏可拖**：左栏、中栏之间的分隔条能拖动调宽，也能用方向键微调；宽度记在本地，下次打开还是你调的样。
- **右键菜单**：笔记卡片上右键出 Obsidian 原生菜单——打开、复制引用、单篇推到云端、从云端拉下来、删除。
- **命令面板与状态栏**：`Ctrl+P` 里有搜索笔记、新建笔记、打开今天的笔记、立即同步、扫描录音卡、**选区速记**、快速切换、在得到大脑里打开当前笔记等命令，不必先打开面板；状态栏常驻一行小字显示本地服务端口与库的大小，点一下打开面板。
- **选区速记**：在任意笔记里选中一段文字，跑「得到大脑：选区速记」，这段文字就落成一篇新笔记——第一行当标题，正文是引用块，末尾注明摘自哪里。摘录和自己的话必须一眼分得开，所以用引用块而不是直接粘。
- **深链**：`obsidian://getnote?action=search&q=关键词`、`action=new|today|sync` 可以直接从任何地方唤起面板并执行对应动作，`action=open&path=...` 则直接跳到某一篇（库内相对路径与面板口径两种写法都收）。只做导航与同步，不做写操作——一个能被任意网页触发的 URL 不该有删笔记的能力。
- **同步摘要写进日记**：面板（或命令面板）跑完一轮同步后，把「新增 N 篇、跳过 M 篇、K 处冲突」追加到当天的日记里（读 Obsidian 日记核心插件的目录与日期格式设置；插件没启用就不写）。

### 云端同步（可选）

两条通道，任选其一或自动回退：

| 通道 | 凭证 | 说明 |
| --- | --- | --- |
| **Open API** | API Key + Client ID + Grant ID | 直接调 `openapi.biji.com`，最省事 |
| **MCP / OAuth** | 浏览器授权（PKCE） | 走 RFC 7591 动态注册，不需要手动申请 Key |

- 单向拉取（云端 → 本地）、逐条推送与「把本地改动推上去」（本地 → 云端）。
  批量推送按内容指纹跳过没改过的笔记，不白吃配额，也不会把云端修改时间刷成现在。
- 图片可选一起下载到 `asset/`。
- 定时自动同步：可设间隔（5–720 分钟）、增量模式、仅面板可见时同步。
- 首次调用失败会自动从 Open API 回退到 MCP 通道，并在状态里标注失败原因。
- 逐字稿与录音联动：点逐字稿里的 `[mm:ss]` 时间戳，播放器跳到那句开始播；播放时正在念的那段会高亮。

### 录音卡导入（可选，需 Python）

- **蓝牙直连**：扫描、读取信息、按文件列表导入、按需删除卡内文件。
- **Wi-Fi 传输**：让卡开热点或连你的路由器，走 HTTP 拉取，比蓝牙快得多。
- 导入后自动按日期与标题命名，写进库并生成 Markdown 笔记；可配置「导入后删卡内文件」。

> 录音卡直连需要 **Python 3.10+** 和 `bleak` 包（`pip install bleak`）。
> 插件会在设置页检测环境，缺什么会直接告诉你。蓝牙是**只读**的：
> 默认永不发送「清理已传输文件」指令，只在你显式勾选「导入后删除」时按文件名删除。

### 其它

- **归档包**：整库导出为 zip、从 zip 导入（可选合并/覆盖模式）。导出可选范围——整库 /
  只要文字 / 只要附件；附件常常比笔记大两个数量级，只想备份文字的人不该每次等几百兆。
- **Bases 视图**：一条命令在笔记目录里生成 `得到大脑.base`——全部 / 按标签 / 按日期三个视图，
  想在 Bases 里自己写公式、自己排表都行，不必回到面板。已经存在就不覆盖（你可能已经调过了），
  但会顺手把它打开——只写文件什么都不发生，会让人以为命令没生效。
- **画布**：一条命令把当前笔记放进 `得到大脑画布.canvas`，没有就新建一张。只补节点，
  不重排你摆好的布局；同一篇加两次也只留一个节点。写完直接打开画布，接着就能拖。
- **模板**：保存常用正文模板，新建时一键套用（最多 12 个）。
- **多语言**：中文 / English / Nederlands。
- **主题**：跟随 Obsidian 主题，深浅色自动适配。
- **贴着宿主走**：界面字体、正文字体、等宽字体与字号都读 Obsidian 的 CSS 变量
  （`--font-interface` / `--font-text` / `--font-monospace` / `--font-text-size`），
  你在外观设置里换字体、调字号、改缩放，面板跟着变；宿主发 `css-change` 时立刻重算。
- **不可逆动作问宿主**：删除、清空、覆盖这类动作弹的是 Obsidian 原生 `Modal`，
  默认焦点在「取消」。移动端 WebView 里 `window.confirm` 可能根本不弹，等于没有二次确认。
- **在 Obsidian 里打开**：面板编辑器只服务「扫一眼、改两笔」，没有补全、没有 Vim、
  没有插件命令。笔记头上一个按钮把它交给宿主编辑器，要动结构就回那边去。
- **反链走宿主的链接索引**：宿主一直在增量维护整库链接图（`metadataCache`），
  面板直接问它，不再为一次反链把全库正文重读一遍。问不到才退回自己扫。
- **窄窗口能收能放**：Obsidian 的侧栏可以只有两三百像素，popout 窗口也能随便拉。
  面板用容器查询盯自己的实际宽度（不是视口宽度——窗口很宽但侧栏很窄是常态）：
  窄了左栏变成抽屉、有笔记时中栏让位，笔记头上有「返回列表」。
- **编辑态跟宿主编辑器一个口径**：Ctrl/Cmd+S 保存、Esc 退出编辑，不用先想起来
  「这是插件里的编辑器」。
- **状态栏跟着面板走**：库里有几篇、当前开着哪一篇，直接写在 Obsidian 的状态栏上，
  点一下打开面板。只有「得到大脑」四个字的话，用户既不知道库多大也不知道在看什么。
- **快速切换器（Ctrl/Cmd+O）**：命令面板里有一条「快速切换：打开得到大脑笔记」，
  列的是库里的全部笔记（带目录前缀，同名笔记分得开），选中就直接在面板里打开。
  找笔记的第一反应是 Ctrl+O，不是翻 ribbon——顺着这个习惯来，库里的笔记才跟宿主
  自己的笔记一样好找。
- **右键菜单里也有我们**：在文件树里右键笔记目录里的 Markdown，多一条「在得到大脑里打开」；
  在编辑器里右键，多一条「把选中的文字存进得到大脑」（没选中就是当前这一行）。只往宿主
  自己的菜单里加条目，不接管菜单——别的插件的条目照旧。笔记目录外的文件不会冒出来。
- **别处改了，面板当场跟着变**：在 Obsidian 编辑器里改了当前这篇、或者把它删了改了名，
  面板立刻跟着换（以前只有重新点一次卡片才重读，开着的那一篇等于停在过去）。
  面板自己保存的那一下不算「别处改了」，不重复读；有没保存的草稿时不覆盖你正在改的内容。
- **列表里能把笔记拖出去**：在列表里按住一篇拖到宿主的编辑器里，落下去就是一条链接
  （格式跟「复制引用」同一套，取决于你自己的链接设置）。想把它引到正在写的那篇里时，
  拖过去比「复制引用 → 切窗口 → 粘贴」顺手。
- **列表里右键就能拿去改**：右键菜单里也有「在 Obsidian 里打开」——扫到一篇想拿宿主的
  补全、Vim、别的插件命令去改时，不必先点开再回头找按钮。面板三种路径口径（库内相对、
  相对笔记目录、绝对）都在交给宿主之前统一换算，右键那条不会因为路径写法不同而找不到文件。
- **复制引用按你的链接习惯来**：点「复制引用」拿到的是 `[[随手记/甲|甲]]` 还是
  `[甲](随手记/甲.md)`，取决于你自己的「使用 Wiki 链接」「新链接格式」设置——这两项
  交给 Obsidian 生成，不是插件自己猜的。粘进另一篇笔记就能用。
- **「今天」用宿主自己的日记模板**：「设置 → 核心插件 → 日记 → 模板文件」指向的那篇
  笔记（标题骨架、几个提问、常用标签），新建今天的日记时会整个填进去——和在宿主里
  新建看到的是同一份。以前我们建一篇空的，同一个库里于是有两种「今天的日记」。
  模板路径宿主记的是库内相对路径，读不到（文件被删、路径写错、插件关着）就当没有。
- **双链带小节也能跳准**：`[[笔记#小节]]`、`[[#本页的小节]]` 在 Obsidian 里会直接滚到
  那一节。以前我们把整串 `笔记#小节` 当路径递过去，宿主找不到这一篇，于是不管点多准都
  只会得到「库里找不到」。现在先切开、把前面那段交给宿主解析，打开之后再按标题文字滚
  过去；同一篇被链到不同小节会显示成「笔记 › 小节」，否则两行链接看起来一模一样，
  点进去落在哪儿全靠猜。那一节被改名或删掉时明说「这一篇里没有这一节」，不是静默不动。
- **这篇引用了谁，也看得见**：笔记底下除了「引用了这篇的笔记」，还会列出这一篇自己
  写了哪些 `[[双链]]`。两个方向合起来才是脑子里那张网——只看反链的话，一篇笔记的
  上下文永远只有一半。出链优先问宿主的索引（它认得别名、竖线前那一段、以及指向库外
  文件的情况），问不到就用读笔记时顺带算好的那份；同一篇写两遍会合掉，点一下就能过去。
- **改名还是宿主那一套**：笔记头、列表右键都能重命名，弹的是 Obsidian 自己的改名
  对话框。这件事不能自己做——宿主改名时会顺手把全库的 `[[双链]]` 和 Markdown 链接
  一起改掉；我们绕过它直接改文件名，别的笔记里的引用就成了死链，往往几个月后才在
  某篇笔记里发现一串点不开的链接。有没保存的改动时先拦住，免得改完重读把那几句
  一起冲掉。
- **图点了就是打开**：面板里的图片（正文里的 `![[图]]` 和附件区的图）点一下交给宿主
  打开——宿主有自己的图片视图，缩放、翻页、拖出去都在那边。以前图片只是「画出来」，
  点上去什么都不会发生；没接上宿主时连光标都不变，不假装能点。
- **图片和录音走宿主的资源协议**：面板里 `<img>` / `<audio>` 的地址问
  `adapter.getResourcePath()`，是宿主自己协议下的地址——浏览器直接加载，吃宿主的缓存，
  录音拖进度条靠的 Range 也归宿主管。以前每张图都要绕一圈本机 HTTP，端口和令牌一换就得重算。
  宿主没给这个方法（旧版本、文件还没进索引）才退回本地服务地址。
- **页面预览也是宿主的**：鼠标停在面板正文里的 `[[双链]]` 上，弹出的预览卡片与在笔记里
  悬停时一模一样——插件只把事件转给宿主，并登记了自己的预览来源。
- **点双链先问宿主的索引**：面板正文里的 `[[双链]]` 该指向哪一篇，先问
  `metadataCache.getFirstLinkpathDest()`——别名、不带扩展名的路径前缀、同名笔记取离当前
  这篇最近的那篇、大小写按库里实际文件名，这些规则都在宿主那儿。面板自己按「路径 → 文件名
  → 标题」三级退让能应付常见的链接，但同名一多就会指到另一篇上，而「点进去是另一篇」这种
  错很难自己发现。宿主解析不出来（或结果落在笔记目录之外）才退回自己那套。
- **popout 窗口里也长一样**：「在新窗口中打开」出来的面板有自己的一份样式，主题跟着
  那个窗口走，Ctrl+K 聚焦的是它自己的搜索框（不抢主窗口的）——宿主每开一个窗口都是一个
  独立的 document，绑在主窗口上的东西在那里面等于不存在。
- **拖进来就是挪过来**：在 Obsidian 左边的文件树里按住一篇笔记，拖到得到大脑的列表上，
  它就挪进你当前筛的那个目录——不用「复制 → 切目录 → 粘贴」。拖进来的是宿主的路径口径
  （带笔记目录前缀），面板自己换算成库里的相对路径再走同一个批量移动接口；没选目录时
  先说一声，不会瞎猜一个地方放。笔记目录外的东西、非 Markdown 文件一律不理。
- **在文件列表里定位**：列表是平的，想知道这篇在库里挨着什么、旁边还有什么时，
  右键「在文件列表里定位」，宿主的文件列表会把它亮出来。老版本挂在核心插件实例上、
  新版本可能只在叶子视图上，两处都试；都没有就明说「这个版本定位不了」，不静默。
- **「今天」就是宿主那个今天**：命令里的「打开今天的笔记」会先问日记核心插件——
  它把日记配在「日记/YYYY/YYYY-MM-DD」还是别的格式，插件就按那个位置找、按那个名字建，
  不会在同一个库里造出第二个「今天」。日记插件关着、或者日记放在笔记目录之外时，才退回
  自己的「库根 + YYYY-MM-DD」——不替用户把日记搬进笔记目录。
- **新建也落在你习惯的地方**：宿主的「设置 → 文件与链接 → 新建笔记的默认位置」配成
  指定目录或「当前笔记所在目录」时，面板里点「+」建出来的那篇就落在那儿，不会同一个库里
  两套「新建落在哪」。你在面板里自己选了目录就以你选的为准（那是你刚明说的）；宿主的设置
  落在笔记目录之外时不跟——不替你把笔记建到笔记目录外面去。
- **反链能看见「在哪一句」**：底下那块「谁提到了我」不再只给标题和路径，每条底下还带
  引用那一行的上下文——一篇笔记里三处都提到你时，扫一眼就知道为什么被引，不用点进去再
  在正文里搜一遍。双链本身从上下文里削掉（`[[名字]]` 这几个字符不占地方），太长就两头
  留一点、中间省略；同一行里写了两遍只留一条（两行一样的字摆出来只是噪音）。提了几次也
  标出来，提得多的排在前面——一篇里反复提到你的，通常比顺口提一次的更值得先看。这个次数
  接不接宿主都一样算，两边排序口径也一样，不会因为宿主的索引还没跑完就换个顺序。
- **断链一次摊出来**：双链写错一个字的时候一点感觉都没有——点下去没反应，过几个月才发现
  一堆死链，那时已经想不起当初想指哪一篇。现在多了一个「断链」页签，点开就把全库指不到的双链
  一次列出来：哪一篇、第几行、那一行长什么样，点一行直接打开出问题的那篇去改。围栏代码块里的
  不算，`[[笔记#小节]]` 只看小节前面那段，指向图片和 PDF 的当附件放过，别名也认——宁可放过，
  也不要把本来没错的链接报成断的，那样你会去改一堆没问题的东西。
- **搜出来就知道它讲的是哪几篇**：搜索结果的卡片原来只有标题、目录和命中次数——知道这篇
  提到了关键词，却不知道它到底在讲哪几篇，还得点进去翻。现在卡片底下直接列出这一篇引用的
  笔记，点胶囊就跳过去，超过四颗收成「+N」。正文本来就已经读进来了，这一行不额外读盘。
- **引用一段就嵌一段**：正文里写 `![[另一篇笔记]]`，那一篇的正文会连同标题一起嵌在
  这里，左边一道竖线分清楚哪段是别人的——跟宿主里看到的一样。只嵌一层：嵌进来的那篇
  里再嵌一篇时留成文件名胶囊，两篇互相嵌入也不会一路读下去；PDF、录音这些附件和解析
  不出来的名字仍然是文件名，不会拿去当笔记读。点嵌入框头上的名字能跳到那一篇。
  `![[笔记#小节]]` 会停在那一节上（不是从头显示），`![[#本节]]` 就是「滚到这一篇的这一节」。
- **别名也算数**：`aliases: [读书笔记]` 之后，`[[读书笔记]]` 在面板里也指得到那一篇——
  以前只比文件名和标题，同一个链接在 Obsidian 里点得开、在面板里报「库里找不到」。别名排在
  最后一级：撞上真实文件名或标题时，真实的那一个更该赢。
- **属性就写在笔记头上**：frontmatter 里的 tags、aliases、你自己加的字段，阅读时摊在正文
  上方一块「属性」里——以前这块完全不显示，你在 Obsidian 里写的标签回到面板里一眼都看不到，
  还以为没存上。标签做成一颗颗可点的胶囊，点一下等于在左栏筛这个标签；空值的键（`aliases: []`
  这种写了等于没写的）不占行，整篇没有头部时这块压根不出现。
- **拖进来就是附件**：把图、录音、PDF 拖到笔记正文上，或者截图之后直接 Ctrl+V，文件会
  存进这篇笔记旁边的 `asset` 目录、正文里自动多一行引用——跟宿主里做的是同一件事。文件名
  带上笔记主干前缀（不然附件区认不出来，你会以为没存进去又拖一遍），同名的不覆盖、自动加
  后缀。有没保存的草稿时只改草稿不落盘，不替你保存半句话；没草稿就直接存好。
- **跟着宿主一起看**：命令面板里一条「在 Obsidian 里打开当前笔记」，把正在 Obsidian 里
  读或改的那篇切到面板里——反链、同步状态、历史版本、附件都在那边。想要它一直跟着也
  可以：设置页里勾上「面板跟着我翻」，之后你在 Obsidian 里翻到哪一篇，开着的面板就切到
  哪一篇。这个开关默认关着（面板自己动，得你点头）：面板没开着时不会替你打开它，不在
  「得到大脑」目录里的笔记也不会跟。

## 安装

### 手动安装（推荐，暂未上架社区市场）

1. 下载 `main.js`、`manifest.json`、`styles.css`，以及 `card/`、`locale/` 两个目录。
2. 放进 `<你的库>/.obsidian/plugins/getnote-obsidian/`。
3. Obsidian 设置 → 第三方插件 → 关闭安全模式 → 启用「得到大脑 Get笔记」。

> `card/` 是录音卡用的 Python 桥脚本，`locale/` 是界面文案。**这两个目录必须一起放**，
> 缺了不影响本地笔记功能，但录音卡与多语言会不可用。

### 从源码构建

```bash
npm install
npm run build      # 产出 main.js，并把 card/ 与 locale/ 复制到插件根
npm test           # 756 项离线测试（需 Node ≥ 22，jsdom 31 依赖 Node 22 的 zstd API）
```

开发时用 `npm run dev` 进入 watch 模式。

推上去之后 GitHub Actions 会跑同一套测试（`.github/workflows/test.yml`）：
`npm ci` + `npm test`，Node 22 / Ubuntu。CI 最后一步还会重新构建一次再
`git status --porcelain main.js card locale`——构建产物和源码不一致（改了源码忘重建、
或重建后忘提交）会直接判失败，免得用户下到的是旧代码。

打标签即发布（`.github/workflows/release.yml`）：`git tag 0.1.0 && git push --tags`
会重跑测试、打包出 `getnote-obsidian-<tag>.zip`（含 `main.js` / `manifest.json` /
`styles.css` / `card/` / `locale/`）挂到 Release 上，可以直接下载解压进插件目录。

## 使用

启用后左侧边栏出现大脑图标，点开即面板；也可以用命令面板：

- `得到大脑：打开面板` —— 在当前工作区打开。
- `得到大脑：在新窗口打开` —— 弹独立窗口，适合双屏。

**第一次用请先设置笔记目录**（设置 → 得到大脑）。默认是库根下的 `得到大脑/`，
你可以改成库内任意目录，插件会自己建。

### 关于本地服务

面板里的图片与音频是浏览器原生资源加载（`<img>` / `<audio>`），
需要真实的 HTTP 地址才能支持 Range 拖动播放，所以插件启动时会在
`127.0.0.1` 上开一个**只绑回环地址**的小服务（端口由系统分配，会记住上次的）。

- 它只监听 `127.0.0.1`，局域网内其它机器访问不到。
- 关闭插件即关闭服务。
- OAuth 登录的回调也走这个地址，所以授权时浏览器要能访问本机。

## 与 DSH 版的差异

| | DSH 版 | Obsidian 版 |
| --- | --- | --- |
| 宿主 | 挂在 DSH `webServer` 的 `/getnote` 前缀路由 | 自带 `127.0.0.1` 回环服务 |
| 库的选择 | 可指向任意绝对路径 | 只能选当前库内的子目录（写入走 `app.vault.adapter`） |
| 界面 | React 三栏，注册进 DSH 的 slot 系统 | 同一个面板（Preact + compat 层），装进 Obsidian `ItemView` |
| 主题 | `--dsw-alias-*` 变量 | 同一批变量映射到 Obsidian 的 `--background-primary` 等 |
| 录音卡 | 同 | 同，但必须 `isDesktopOnly`（要起子进程） |

之所以「不能直接复制」，主要就在这几层接线；核心逻辑（vault / archive / history /
cloud-sync / openapi / biji / card 与 Python 桥）是同一份代码，测试也是同一套。

## 目录结构

```
src/
  main.js            插件入口：加载设置、起服务、注册视图与命令
  host/server.js     127.0.0.1 回环 HTTP 服务（CORS + Range）
  core/
    service.js       /getnote/* 全部路由（从 DSH 版原样搬来）
    vfs.js           文件系统适配层：绝对路径 → app.vault.adapter
    vault.js         笔记库算法（扫描、搜索、冲突、历史、标签……）
    settings.js      设置读写（存插件数据目录，不进库）
    net.js           用 node:http 实现的 fetch 兼容层（绕开渲染进程 CORS）
    openapi.js  biji.js  mcp-cloud.js  cloud-sync.js  sync.js
    archive.js  history.js  card.js
  view/
    panel.js         面板本体（从 DSH 版机械移植，React 写法，跑在 Preact 上）
    view.js          ItemView 外壳
  card/*.py          录音卡 Python 桥（蓝牙 / Wi-Fi）
  locale/*.json      界面文案
```

## 已知限制

- **仅桌面端**：录音卡要起 Python 子进程，移动端不可用。
- **录音卡导入依赖系统 Python**，且 `bleak` 版本需支持你的系统蓝牙栈。
- Wi-Fi 传输的 IP 探测依赖 `netsh`（Windows），其它平台回退到系统路由表。
- 云端接口是「得到大脑」的非公开 API，可能随对方调整而变化；凭证只存在本地。
